# ADR-0010: The apparatus cap

**Status:** accepted (2026-06-05)

**Context.** The failure mode for this project is not technical debt. The
schema, the quarantine, the ADRs, the badges are all cheap, all good, and all
seductive in a way that prose about grounding rods and tower leases is not.
The stub graveyards of prior art did not die from bad frontmatter; they died
from the writing stopping.

**Decision.** All scaffolding — toolchain, schema, deployment, redirects,
analytics (Cloudflare Web Analytics: zero-infra script tag), this decision
log — gets **one setup pass, then it is done**. From that point, progress is
measured in **published journey-stage words only**. New apparatus requires a
demonstrated writing-workflow problem, not an anticipated one.

**Consequences.** Future "wouldn't it be nice if the build also…" ideas are
rejected by default. The scaffolding serves the writing.

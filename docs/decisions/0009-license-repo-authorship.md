# ADR-0009: CC BY 4.0, public repo, named authorship

**Status:** accepted (2026-06-05)

**Context.** The site's entire strategy rests on being citable and trusted:
readers make five-figure decisions on it, LLMs increasingly mediate discovery,
and the `lastReviewed` promise needs a correction workforce bigger than one
person.

**Decision.** Content is **CC BY 4.0** (maximally citable; author retains
relicensing rights over own text); site code is MIT. The repo is **public on
GitHub** with edit-this-page and report-outdated links on every page,
converting readers — and WISP operators are exactly the audience that files
corrections — into the currency-audit workforce. Authorship is **named, with
credentials**, on the About page; a reference work by someone who has done the
work beats an anonymous guide.

**Consequences.** If outside contributions grow, a CLA may be needed before
any relicensing (contributed text is the contributors' under CC BY).
Disclaimer posture (ADR-0010 territory, folded into About): the handbook
describes the landscape, it is not professional training; safety- and
law-adjacent pages say when to hire a professional, as first-class content.
